# 导入与导出

Super IO 保留了最简单的工作流：在 Blender 外复制，在 Blender 里粘贴。

## 导入

从文件管理器复制文件后，在 Blender 里按 `Ctrl+Shift+V`。Super IO 会读取剪贴板路径、当前编辑器和自定义配置，然后选择合适的导入流程。

常见导入包括：

- OBJ、STL、PLY、FBX、glTF、SVG 等 Blender 支持的格式。
- blend 文件，以及更细分的追加/链接选项。
- 图片作为参考图、平面、着色节点、世界纹理或资产预览。
- 用于材质和贴图工作流的文件夹。

当同一种格式匹配到多个自定义规则时，Super IO 会弹出菜单让你选择具体预设。

## 导出

在 3D 视图选择对象后按 `Ctrl+Shift+C`，即可打开导出菜单。Super IO 会通过 Blender 的导出器导出选中对象，并把结果放到剪贴板中。

图像工作流可以把当前图片导出为文件，也可以在支持的场景中把结果粘贴到其它应用或文件管理器。

## 编辑器上下文

同样的剪贴板内容，在不同编辑器里可以有不同处理方式：

- 在 3D 视图中，图片可以作为参考图或图片平面导入。
- 在着色器编辑器和几何节点中，图片可以作为纹理节点导入。
- 在图像编辑器中，剪贴板图片操作会使用 Blender 的图片剪贴板 API。
